# iPhone 일정 기상 알람

아이폰 단축어의 일정 기반 기상 알람 자동화를 기록하고 변경 이력을 관리하는 프로젝트입니다.

## 현재 구성

아이폰에는 다음 일일 자동화가 이미 있습니다.

- `일정 기상 알람`: 매일 00:05 실행
- `일정 기상 알람 (05시 보강)`: 매일 05:00 실행

따라서 이 레포는 새 자동화를 중복 생성하지 않고 현재 구성을 문서화합니다. 실제 실행은 아이폰의 단축어 앱과 시계 앱이 담당합니다.

## 버전 관리 범위

GitHub에는 읽을 수 있는 동작 명세와, 민감한 값이 없는지 확인한 내보내기 파일만 둡니다. 캘린더 일정·알람 목록·계정 정보·기기 식별자는 저장하지 않습니다. Shortcut 내보내기 파일은 Git에서 내부 동작을 줄 단위로 비교하기 어렵기 때문에, 함께 관리하는 문서가 변경 검토의 기준입니다.

## 파일

- `docs/current-state.md`: 아이폰에서 관찰한 현재 구성과 확인이 더 필요한 부분
- `docs/maintenance.md`: 변경 및 백업 기록 방법

## 상태

2026-10-14 기준 아이폰의 두 자동화 이름과 실행 시각, 기본 필터 구성을 확인했습니다. 전체 동작을 끝까지 대조하고 실제 실행 결과를 확인하는 검증은 아직 완료되지 않았습니다.
