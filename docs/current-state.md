# 현재 아이폰 설정

마지막 관찰: 2026-10-14, iPhone 단축어 앱

## 자동화

| 이름 | 트리거 | 상태 |
| --- | --- | --- |
| `일정 기상 알람` | 매일 00:05 | 아이폰 목록에서 확인 |
| `일정 기상 알람 (05시 보강)` | 매일 05:00 | 아이폰 목록에서 확인 |

## `일정 기상 알람`에서 읽은 동작

- 시간 트리거가 있습니다.
- 기존 알람에서 이름에 `일정 기상`이 들어가고 켜져 있는 항목을 찾습니다.
- 캘린더에서 시작일이 오늘이고 종일 일정이 아닌 항목을 찾습니다.
- 제목이 `[녹강]`과 같은 일정만 남기는 필터가 있습니다.
- 시작 시간이 가장 빠른 일정부터 정렬하고 1개를 가져옵니다.
- 일정이 있고 켜진 `일정 기상` 알람이 없을 때, 일정 시작 시각에서 105분을 빼 새 `일정 기상` 알람을 만듭니다.
- 이름에 `일정 기상`이 포함되고 꺼진 알람을 찾는 정리 분기도 있습니다. 분기 조건과 삭제 대상은 아직 확인이 필요합니다.

## `일정 기상 알람 (05시 보강)`에서 읽은 동작

- 매일 05:00에 실행되며 자동화 스위치가 켜져 있습니다.
- 오늘 시작하는 종일이 아닌 일정을 찾고, 제목에 `[녹강]`이 포함되지 않는 조건을 확인했습니다.
- 찾은 일정의 시작 시각에서 105분을 빼 `일정 기상` 알람을 만드는 동작이 있습니다.
- 전체 정리 분기와 실제 실행 이력은 아직 확인하지 않았습니다.

## 2026-10-14 알람 확인

- Google Calendar에서 오늘 컴퓨터네트워크 수업은 09:00 시작으로 조회됐고, 오늘 시작 시각이 00:00인 일정은 검색 결과에 없었습니다.
- 시계 앱에서 07:15 알람을 확인했습니다. 이름에 오늘 수업 제목이 포함되어 있고, 09:00에서 105분 뺀 시각과 일치합니다.
- 해당 알람 스위치는 조회 시점에 꺼져 있었습니다. 이 화면은 생성 시각이나 실제로 소리가 났는지 기록하지 않습니다.
- 자동화 실행 기록과 알람 생성 시각은 확인되지 않아, 05:00 보강 자동화가 오늘 새로 만들었는지와 알람이 울렸는지는 확정하지 않습니다. 시계에 해당 알람 항목이 있는 만큼 알람 항목 자체가 없었던 것은 아니지만, 오늘 생성된 항목인지까지는 알 수 없습니다. 따라서 "생성 실패"보다는 "알람 항목은 확인되며, 실제 울림 여부는 미확인"이 현재 근거에 맞는 결론입니다.

## 검증 상태

- 확인됨: 두 자동화의 제목 필터 차이, 첫 일정 선택, 105분 전 알람 생성, 오늘 07:15 알람 항목 존재
- 미확인: 꺼진 알람 정리 분기의 정확한 조건과 대상, 오늘 자동화 실행 시각, 알람이 실제로 울렸는지, 자동화별 실행 알림
- 이 문서는 현재 아이폰 화면에서 읽은 설정 기록입니다. 실제 날짜별 실행을 입증하지 않습니다.

## 개인정보

실제 일정 제목·시간·참석자, 알람 목록, 계정 정보, 기기 ID는 이 문서에 기록하지 않습니다. 자동화 파일을 내보내거나 공유하기 전에 포함된 개인정보를 확인합니다.
