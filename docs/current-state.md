## `일정 기상 알람`에서 읽은 동작

- 시간 트리거가 있습니다.
- 기존 알람에서 이름에 `일정 기상`이 들어가고 켜져 있는 항목을 찾습니다.
- 캘린더에서 시작일이 오늘이고 종일 일정이 아닌 항목을 찾습니다.
- 현재 화면에서 제목 필터 값은 `[녹강]`으로 보였습니다. 의도한 조건인지와 다른 필터와의 관계는 아직 확인이 필요합니다.
- 시작 시간이 가장 빠른 일정부터 정렬하고 1개를 가져오는 설정을 확인했습니다.
- 조건 분기 이후의 알람 생성·정리 동작과 05:00 보강 자동화의 전체 동작은 아직 끝까지 확인하지 않았습니다.

## 검증 상태

- 확인됨: 두 자동화의 이름과 일일 실행 시각, 기본 필터 일부
- 미확인: 전체 단축어 동작, 빈 일정일 때의 처리, 기존 알람 교체 방식, 실제 알람 생성 결과, 자동화별 실행 알림
- 이 문서는 현재 아이폰 화면에서 읽은 설정 기록입니다. 실제 날짜별 실행을 입증하지 않습니다.

## 개인정보

실제 일정 제목·시간·참석자, 알람 목록, 계정 정보, 기기 ID는 이 문서에 기록하지 않습니다. 자동화 파일을 내보내거나 공유하기 전에 포함된 개인정보를 확인합니다.
