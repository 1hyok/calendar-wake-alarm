# 현재 아이폰 설정

## 자동화

| 이름 | 트리거 | 상태 |
| --- | --- | --- |
| `일정 기상 알람` | 매일 00:05 | 아이폰 목록에서 확인 |
| `일정 기상 알람 (05시 보강)` | 매일 05:00 | 아이폰 목록에서 확인 |

## `일정 기상 알람`에서 읽은 동작

- 시간 트리거가 있습니다.
- 기존 알람에서 이름에 `일정 기상`이 들어가고 켜져 있는 항목을 찾습니다.
- 캘린더에서 시작일이 오늘이고 종일 일정이 아닌 항목을 찾습니다.
- 현재 화면에서 제목은 `[녹강]`과 같은 일정만 남기는 필터로 보였습니다. 이 조건이 의도한 것인지 확인이 필요합니다.
- 시작 시간이 가장 빠른 일정부터 정렬하고 1개를 가져옵니다.
- 일정이 있고 켜진 `일정 기상` 알람이 없을 때, 일정 시작 시각에서 105분을 빼 새 `일정 기상` 알람을 만듭니다.
- 이름에 `일정 기상`이 포함되고 꺼진 알람을 찾는 정리 분기도 있습니다. 분기 조건과 삭제 대상은 아직 확인이 필요합니다.
- 05:00 보강 자동화의 전체 동작은 아직 확인하지 않았습니다.

## 검증 상태

- 확인됨: 주 자동화의 캘린더 검색 조건, 첫 일정 선택, 105분 전 알람 생성, 기존 알람 중복 확인 일부
- 미확인: `[녹강]` 제목 필터의 의도, 꺼진 알람 정리 분기의 정확한 조건과 대상, 05:00 보강 자동화의 전체 동작, 실제 알람 생성 결과, 자동화별 실행 알림
- 이 문서는 현재 아이폰 화면에서 읽은 설정 기록입니다. 실제 날짜별 실행을 입증하지 않습니다.

## 개인정보

실제 일정 제목·시간·참석자, 알람 목록, 계정 정보, 기기 ID는 이 문서에 기록하지 않습니다. 자동화 파일을 내보내거나 공유하기 전에 포함된 개인정보를 확인합니다.
