# 변경 및 백업

1. 단축어를 변경하기 전에 아이폰의 현재 자동화 동작을 확인하고 `current-state.md`를 갱신합니다.
2. 바뀐 조건, 동작, 트리거 시각과 아이폰에서 확인한 결과를 함께 기록합니다.
3. Shortcut 내보내기 파일을 추가할 때는 파일을 열거나 공유하기 전에 개인 일정, 알람 값, 계정 또는 다른 개인 데이터가 포함되는지 검토합니다.
4. 테스트는 별도 테스트 일정과 임시 알람으로 수행합니다. 실제 개인 일정을 시험 데이터로 복사하지 않습니다.
5. GitHub는 백업과 문서 변경 이력에 사용합니다. 레포의 문서만으로 아이폰에 자동화를 설치하거나 동기화하지 않습니다.
